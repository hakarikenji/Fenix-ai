Give Coder mode a way out, so a mode is never a one-way door

Entering Coder mode had no exit. selectProject was the only thing that ever
changed the project, the drawer had no "no project" entry, and the "⚡ Coder"
label was a dead span. The only ways out were deleting the project or signing
out — both of which destroy something the user wanted to keep.

The label is now a real button that opens a menu with "Back to normal chat",
the project files, switching project and both chat brains. Tapping the
project you are already in also leaves Coder mode, the drawer has a "Normal
chat" row, and the Coder welcome screen carries a visible exit.

Leaving keeps everything: the project, its files and the conversation. Picking
a chat brain from the menu leaves Coder too, because otherwise the choice
would look like it did nothing.

Two related traps are closed as well: a signed-out visitor used to boot into a
Coder-mode label for a project they no longer own, and a project deleted
elsewhere left the mode switched on forever.

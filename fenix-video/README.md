# 🎬 Fenix Video — مولّد الفيديو بالذكاء الاصطناعي

**Fenix** — شركة العنقاء 🦅: تطبيقات عالمية حديثة، مجانية بالكامل. كل تطبيق مستقل تماماً
ولكل تطبيق **عقله الخاص بمجاله** (LoRA مدرّب) يعمل بجانب العقل الرئيسي **Fenix Core**.

تطبيق Fenix Video: حوّل فكرتك إلى **فيديو قصير كامل** — سيناريو مشهد-بمشهد بالعقل،
صور مشاهد مولّدة بالذكاء الاصطناعي، تعليق صوتي TTS، وموسيقى — والرندر يتم **بجهازك**
(بدون خادم GPU، بدون رصيد، مجاني 100%).

## ماذا يفعل

| الميزة | الشرح |
|---|---|
| 📝 سيناريو بالعقل | فكرتك → مشاهد كاملة: وصف بصري + تعليق صوتي + مدة كل مشهد |
| 🖼️ صور مشاهد AI | كل مشهد → صورة مولّدة (مجاني، بدون مفتاح) |
| 🎙️ تعليق صوتي | TTS مجاني بالمتصفح (Web Speech) — بأي لغة من لغات التطبيق |
| 🎵 موسيقى خلفية | من استوديو Fenix Music أو ملف ترفعه بنفسك |
| 🎞️ رندر محلي | Canvas + MediaRecorder داخل الجهاز → WebM جاهز للتحميل والمشاركة |
| 🧠 سلسلة العقول | fenix-video (المدرّب لاحقاً) → fenix-core (الحي) → Gemini |

## البنية (نفس كور Fenix)

```
fenix-video/
├── server.py            # خادم Flask: /api/script /api/scene-image /api/config
├── api/brain.py         # سيناريو الفيديو بالعقل (سلسلة العقول + Gemini)
├── web/index.html       # الاستوديو (PWA جاهز للتغليف بـ Capacitor كـ APK)
├── web/manifest.json    # PWA
├── web/sw.js            # offline shell
├── training/            # رحلة تدريب عقل الفيديو (نفس نمط Fenix Music)
├── requirements.txt
└── README.md
```

## التشغيل

```bash
pip install -r requirements.txt
python server.py          # يعمل على PORT (افتراضي 8000)
```

## متغيرات البيئة

| المتغير | الوظيفة | مطلوب؟ |
|---|---|---|
| `GEMINI_API_KEY` | الاحتياط الأخير للسيناريو | يفضّل |
| `GEMINI_MODEL_CHAIN` | سلسلة نماذج Gemini الاحتياطية | لا (افتراضي حي) |
| `CORE_BRAIN_URL` | عقل Fenix Core (افتراضياً رابط Hakari الحي) | لا — مدمج |
| `VIDEO_BRAIN_URL` | عقل fenix-video المدرّب (لما يدرب) | لا |
| `HF_TOKEN` | اختياري: صور بديلة عبر Hugging Face | لا |

## كيف يعمل (مجاني 100%)

1. **السيناريو**: العقل يكتب 4-8 مشاهد (وصف بصري إنجليزي + جملة تعليق + ثوانٍ)
2. **الصور**: كل مشهد → Pollinations (مجاني بدون مفتاح) — أو HF إذا وضع `HF_TOKEN`
3. **الصوت**: تعليق TTS بالمتصفح + موسيقى اختيارية من Fenix Music أو ملفك
4. **الرندر**: يرسم الصور مع الكينغ متناسق على Canvas، يسجل الصوت والصورة معاً
   بـ MediaRecorder → **video.webm** تنزّله وتنشره فوراً

## خطوة العقل المدرّب (لاحقاً)

نفس رحلة Fenix Music حرفياً: بيانات سيناريوهات JSONL → `training/train_modal.py`
(A10G LoRA) → `modal deploy training/serve_modal.py` → ضع الرابط في `VIDEO_BRAIN_URL`.

**Fenix AI** (المساعد الشخصي) · **Fenix Music** (عقل الموسيقى) · **Fenix Video** (عقل الفيديو) · قادم: منشئ التطبيقات 🛠️
